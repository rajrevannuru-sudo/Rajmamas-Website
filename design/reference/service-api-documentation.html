FAQ

API documentation questions

Do you need access to our codebase?

Access to your API, its spec and a test environment is usually enough. Read access to the repository helps for SDK guides, and we work under NDA.

Can you work from an OpenAPI spec?

Yes. We can improve and extend your existing spec, or help you create one, and generate the reference from it.

Will our engineers have to write anything?

No. We need short interviews and reviews from them. We do the writing and testing.

How do we keep the docs current after launch?

We deliver a style guide and templates, and can support you monthly as the API changes.
